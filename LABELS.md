# Page Feed Label Reference

A plain-English guide to every label the feed can produce, and what it means.
This is the client-facing companion to the "Label Taxonomy" tab in the
monthly `.xlsx` report — same information, explained rather than just listed.

## How to read a label

Every URL in the feed gets one `Custom label` value: several labels joined
with semicolons, one from each dimension that applies to that page. For example:

```
https://www.riparide.com/listings/97-pebble-point
PAGE_LISTING;GEO_AU;GEO_VIC;REG_GREAT_OCEAN_ROAD;TYPE_GLAMPING;PMAX_LONGTAIL
```

Reading left to right: this is a **listing page**, in **Australia**, in
**Victoria**, in the **Great Ocean Road** region, for a **glamping** stay,
and it's in **PMax's proven territory** (not held back for any reason). Six
possible dimensions in total — a page only carries the ones that apply to it,
so a lot of labels are shorter than this.

---

## 1. Page type — what kind of page this is

| Label | Meaning |
|---|---|
| `PAGE_LISTING` | An individual property listing |
| `PAGE_STORY` | An individual story/editorial page about a stay |
| `PAGE_ADVENTURE` | An individual "things to do" adventure page |
| `PAGE_COUNTRY` | A top-level country page (e.g. the Australia hub) |
| `PAGE_STATE` | A state-level hub page (e.g. Victoria) |
| `PAGE_REGION` | A region-level hub page (e.g. Great Ocean Road, High Country) |
| `PAGE_COLLECTION_HUB` | The index page listing all collections for a country/state |
| `PAGE_COLLECTION` | An individual themed or destination collection page |
| `PAGE_FACET_TYPE` | A synthetic search-results URL for one stay type in one geo scope, generated by this system rather than crawled — see [§4](#4-stay-type--what-kind-of-accommodation) |
| `PAGE_CORE` | A brand/informational page (About, Contact, etc.) — **excluded from both feeds entirely**, not just held back |

---

## 2. Geo — country and state

Two separate labels, always paired: a country label, and (where applicable) a state label.

| Label | Meaning |
|---|---|
| `GEO_AU` | Australia |
| `GEO_NZ` | New Zealand |
| `GEO_US` | United States |
| `GEO_VIC` | Victoria, Australia |
| `GEO_NSW` | New South Wales, Australia |
| `GEO_WA` | Washington State, USA |
| `GEO_OR` | Oregon, USA |

New Zealand has no state-level label — the country label alone is enough for it.

---

## 3. Region — the specific area

Every region gets a label built directly from its name — for example, "Yarra
Valley" becomes `REG_YARRA_VALLEY`. There's no fixed list here; a region
label exists for every region region-hub page riparide.com actually publishes.

**One wrinkle worth knowing about**: three region names exist in more than
one place — `north-coast`, `south-coast`, and `central-coast` each exist in
both New South Wales and Oregon. For those three only, the state or country
is appended to keep them distinct: `REG_NORTH_COAST_NSW` vs `REG_NORTH_COAST_OR`,
and so on. Every other region label is just the name itself, no suffix.

If a brand-new region is ever added to the site and it happens to collide
with an existing one in a different state/country, the system detects and
reports that automatically rather than silently merging the two.

## 4. Stay type — what kind of accommodation

**From the site's own filter categories** (22 in total):

`TYPE_A_FRAME`, `TYPE_BARN`, `TYPE_BEACH_SHACK`, `TYPE_CABIN`, `TYPE_CAMPING`,
`TYPE_CARAVAN`, `TYPE_CHURCH`, `TYPE_COTTAGE`, `TYPE_ECO_HOUSE`, `TYPE_FARM`,
`TYPE_GLAMPING`, `TYPE_HOUSE`, `TYPE_LODGE`, `TYPE_LUXURY_HOUSE`,
`TYPE_SHIPPING_CONTAINER`, `TYPE_STUDIO`, `TYPE_SUITE`, `TYPE_TINY_HOUSE`,
`TYPE_TRAIN`, `TYPE_TREEHOUSE`, `TYPE_VILLA`, `TYPE_YURT`

**Wordings the site uses that aren't one of the 22 filter categories above,**
but still deserve their own label rather than being forced into the nearest
match (a beach house isn't a beach shack, and getting that wrong would put a
listing in the wrong campaign group):

| Label | Meaning |
|---|---|
| `TYPE_BEACH_HOUSE` | Beach house |
| `TYPE_TRAIN_CARRIAGE` | Train carriage stay |
| `TYPE_HOUSEBOAT` | Houseboat |
| `TYPE_HOTEL` | Hotel |
| `TYPE_VEHICLE` | Vehicle-based stay (e.g. a converted van) |
| `TYPE_TIPI` | Tipi |
| `TYPE_KILN` | Converted kiln |
| `TYPE_CAVE` | Cave stay |
| `TYPE_IGLOO` | Igloo |

**What happens with a wording that's genuinely new** (not in either list
above): it never gets guessed at or forced into a near-match. It's recorded
and reported in the monthly summary as "seen but not mapped," so it can be
added deliberately once confirmed — this is a safety choice, not a gap: a
wrong guess would misfile a listing, a reported-but-unlabelled one just
doesn't get a stay-type label yet.

**About `PAGE_FACET_TYPE` pages specifically**: for each of the 22 filter
categories above, the system also generates one search-results-style URL per
geo scope (Australia, Victoria, NSW, New Zealand, Washington, Oregon) — 132
of these in total. These aren't individual listings; they're the "show me
all glamping stays in Victoria" style page, included so Google Ads can match
a broader search to the right filtered results page instead of a single
property.

## 5. Intent — what the Explorer is specifically looking for

Detected from words in the URL itself. Up to two intent labels per page.

| Label | Meaning | Matched from |
|---|---|---|
| `INT_ROMANTIC` | Romantic getaway | "romantic", "honeymoon", "couples" |
| `INT_OFFGRID` | Off-grid stay | "off-grid", "offgrid" |
| `INT_PET_FRIENDLY` | Pet/dog-friendly | "pet-friendly", "dog-friendly" |
| `INT_FARM_STAY` | Farm stay | "farm-stay", "farmstay" |
| `INT_HOT_TUB` | Has a hot tub | "hot-tub", "hottub" |
| `INT_SAUNA` | Has a sauna | "sauna" |
| `INT_GROUPS` | Suited to groups | "split-the-bill", "split-the-check", "groups" |
| `INT_LUXURY` | Positioned as luxury | "luxury" |
| `INT_GETAWAY` | General weekend-getaway framing | "getaway" (also catches "getaways", "weekend-getaway") |

Four of these — **romantic, off-grid, pet-friendly, and getaway** — are
specifically flagged in the boundary dimension below, because SNR's research
found Google Search ads outperform Performance Max by 2x or more on exactly
these themes.

## 6. Boundary — where this page should (and shouldn't) be advertised

This is the most business-meaningful label on any given page — it controls
which campaign a page is eligible to appear in.

| Label | Meaning |
|---|---|
| `PMAX_LONGTAIL` | Performance Max's proven, default territory — no restriction |
| `SEARCH_HEAD` | Google Search (not PMax) performs meaningfully better here — romantic, off-grid, pet-friendly, or general-getaway intent, or one of four "search-favoured" stay types (tiny house, cabin, glamping, cottage) on the synthetic filter pages specifically |
| `NZ_REVIEW` | New Zealand — held back from paid campaigns pending a performance review (NZ's PMax return has been underwhelming) |
| `US_HOLD` | United States — held back entirely; the US isn't currently a paid market for Riparide |
| `ADV_HOLD` | Adventure/"things to do" pages — held back because these are editorial content, not something to run ads against directly |

**One thing worth flagging honestly**: the `SEARCH_HEAD` stay-type rule
(tiny house, cabin, glamping, cottage) is currently an inference from the
intent-based research, not something separately confirmed for stay types
specifically — see `DECISIONS.md` D8 for the full reasoning. It only affects
the 132 synthetic filter pages, not individual listings or stories.

## Which feed a page actually ends up in

Every page falls into exactly one of three buckets:

- **Core feed** — everything except adventures and brand pages. This is what most of the taxonomy above describes.
- **Adventures feed** — kept separate because these pages carry different labels (mainly intent + `ADV_HOLD`) and serve a different purpose.
- **Excluded entirely** — brand/informational pages (`PAGE_CORE`) never appear in either feed.
